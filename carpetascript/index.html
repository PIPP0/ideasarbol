Esta página es pública. Semilla.gs incluye el contenido de tus ideas. Cuando termines de instalar en Apps Script, pide que se elimine esta carpeta.
Si el aviso rojo dice «NO SE EJECUTÓ EL CARGADOR»: tu archivo App es el antiguo. Recarga esta página con Cmd+Shift+R, copia el archivo 6 (App) y pégalo reemplazando todo. Cómo comprobar que quedó bien: en Apps Script, el nuevo App tiene unas 1.980 líneas y empieza con «Cargador del código de la aplicación» y luego letras y números sin sentido; el antiguo tiene 3.222 líneas de código normal.
  1. En script.google.com, con tu cuenta del trabajo, abre tu proyecto.
  2. Para cada fila de abajo: pulsa + → Script o HTML (según se indica) y escribe el nombre exactamente como aparece, sin extensión.
  3. Pulsa Copiar aquí, borra lo que trae el archivo en Apps Script y pega.
  4. El manifiesto (archivo 1) va en ⚙ Configuración del proyecto → «Mostrar el archivo de manifiesto appsscript.json».
  5. Al terminar: ejecuta la función instalar y luego Implementar → Nueva implementación → Aplicación web (Ejecutar como: Yo · Acceso: personas de mi organización).
